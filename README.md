# usend OpenAPI

The OpenAPI 3 description of the [usend](https://usend.et) email API (`openapi.yaml`). Use it to generate a client in any language or to import the API into your tooling.

Official SDKs: [Node.js](https://github.com/usend/usend-node), [Python](https://github.com/usend/usend-python), [Go](https://github.com/usend/usend-go), [PHP](https://github.com/usend/usend-php), [Ruby](https://github.com/usend/usend-ruby), [Java](https://github.com/usend/usend-java), [.NET](https://github.com/usend/usend-dotnet), [Elixir](https://github.com/usend/usend-elixir), [Rust](https://github.com/usend/usend-rust).

This repository is a mirror: the spec is maintained in the main usend repository and synced here.
